# Схема БД Filmorate

Документ фиксирует стартовую схему, созданную в Flyway-миграциях `V1__init_schema.sql` и `V2__seed_reference_data.sql`. Комментарии в SQL намеренно подробные, чтобы упростить сопровождение.

## Основные сущности
- **users** — пользователи с уникальными `email` и `login`, плюс технический `created_at` для отладки.
- **films** — фильмы с рейтингом `mpa_id`, описанием и датой релиза.
- **reviews** — отзывы пользователей с признаком `is_positive` и агрегированной полезностью `useful`.
- **events** — лента активности (LIKE/REVIEW/FRIEND) с операциями ADD/REMOVE/UPDATE.

## Справочники
- **mpa** — возрастные рейтинги (G, PG, PG-13, R, NC-17).
- **genres** — шесть базовых жанров: Комедия, Драма, Мультфильм, Триллер, Документальный, Боевик.
- **directors** — режиссёры, привязанные к фильмам через таблицу связей.

## Связи многие-ко-многим
- **film_genre** — связывает фильмы и жанры, не допускает дубликатов одной пары.
- **film_director** — связывает фильмы и режиссёров.

## Социальные взаимодействия
- **likes** — лайки фильмов от пользователей (по одному на пару фильм/пользователь).
- **friendships** — двусторонние дружбы между пользователями, запрещает дружбу с самим собой.
- **review_ratings** — лайки и дизлайки отзывов (столбец `is_positive`), используются для расчёта `useful`.

## Индексы
Для ускорения типовых запросов добавлены индексы по внешним ключам (`mpa_id`, `user_id`, `friend_id`, `film_id`) и для ленты событий.

Эта схема покрывает текущие репозитории (лайки, дружба, отзывы, рекомендации) и даёт основу для расширений без изменения уже созданных таблиц.
